# BomberPrototype

A **Bomberman-style prototype** built in **Unreal Engine 4 C++** — a modern take on the classic NES game.

Grid-based movement, bomb placement with timed explosions, destructible blocks, and enemy behavior — the core Bomberman loop implemented as a clean UE4 C++ prototype.

## Features
- Grid-aligned player movement
- Bomb placement, fuse timer, blast propagation
- Destructible blocks and enemy placement
- Score/round reset flow

## Requirements
- Unreal Engine 4.18+ (C++ project — VS 2019+ on Windows to build)

## How to run
1. Clone the repository.
2. Open `BomberManPrototype.uproject` in UE4.
3. Press **Play**.

## Controls
- Arrow keys / WASD — move
- Space — place bomb
